# C++ Programming Solutions & OOP

Репозиторий содержит коллекцию программ на C++, включающую задачи с LeetCode и Codeforces, примеры по ООП и упражнения из сборника задач.

## Структура проекта

<pre>
Cpp_codes/
├── 1000_zadach_po_programmirovaniju/  # Задачи из учебного сборника
├── codeforces/                        # Решения задач с Codeforces
├── leetcode_tasks/                    # Задачи с LeetCode
└── oop_basics/                        # Теория и ООП-практика
</pre>

## Как запустить

Для сборки и запуска необходим компилятор C++11 или выше:

1. Склонируйте репозиторий: `git clone https://github.com`
2. Перейдите в папку с проектом и скомпилируйте нужный файл с помощью g++.
3. Запустите полученный исполняемый файл.

## Требования

* Компилятор G++ (GCC) или Clang
* Текстовый редактор или IDE
