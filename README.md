# C++ Programming Solutions & OOP

Репозиторий содержит коллекцию программ на языке C++, разделенную на две основные категории: решения алгоритмических задач с платформы LeetCode и практические примеры для изучения объектно-ориентированного программирования (ООП).

## Описание разделов

* **leetcode_tasks/** — Решения популярных задач на массивы и циклы с LeetCode. Каждое решение оформлено в виде связки заголовочного файла (.h) и файла реализации (.cpp) для модульности кода.
  * *Concatenation of Array* — Задача на дублирование элементов массива.
  * *Max Consecutive Ones* — Поиск максимального количества идущих подряд единиц в бинарном массиве.
  * *Shuffle the Array* — Задача на тасование элементов массива по заданному правилу.

* **oop_basics/** — Примеры кода для освоения базовых концепций C++.
  * *классы_конструкторы.cpp* — Изучение создания классов, принципов работы конструкторов и деструкторов.
  * *перегрузки.cpp* — Реализация перегрузки функций и операторов в C++.

## Как запустить

Для сборки и запуска программ вам понадобится компилятор, поддерживающий стандарт C++11 или выше (например, GCC/g++).

1. Склонируйте репозиторий:
git clone https://github.com

2. Перейдите в папку с нужным решением:
cd Cpp_codes/leetcode_tasks

3. Скомпилируйте файлы (для работы классов нужно компилировать .cpp файл решения вместе с вашим файлом main.cpp, где находится точка входа):
g++ Shuffle.cpp main.cpp -o shuffle

4. Запустите исполняемый файл:
./shuffle

## Требования

* Компилятор G++ (GCC) или Clang c поддержкой стандарта C++17
* Текстовый редактор или IDE (VS Code, Visual Studio, CLion)
