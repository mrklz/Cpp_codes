# C++ Programming Solutions & OOP

Репозиторий содержит коллекцию программ на языке C++, включая решения задач с LeetCode, Codeforces, сборника задач и примеры по ООП.

## Структура проекта

<pre>
Cpp_codes/
├── 1000_zadach_po_programmirovaniju/  # Задачи из учебного сборника
├── codeforces/                        # Решения задач с Codeforces
├── leetcode_tasks/                    # Задачи с LeetCode
└── oop_basics/                        # Теория и ООП-практика
</pre>

## Краткое описание

Репозиторий включает разделы с задачами из учебных сборников, олимпиадными решениями (Codeforces, LeetCode) и практическими примерами по объектно-ориентированному программированию на C++.

## Как запустить

Для сборки проектов требуется стандартный компилятор C++11 и выше (G++ или Clang). Подробности компиляции и клонирования доступны в структуре репозитория.
