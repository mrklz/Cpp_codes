# C++ Programming Solutions & OOP

Репозиторий содержит коллекцию программ на языке C++, разделенную на три логических блока: решения алгоритмических задач с платформ LeetCode и Codeforces, а также практические примеры для изучения объектно-ориентированного программирования (ООП).

## Описание разделов

* **codeforces/** — Решения популярных олимпиадных задач на C++ с платформы Codeforces.
  * *Soldier and Bananas* — Задача на циклы и базовую арифметику (расчет нехватки денег на покупку бананов).
  * *Word Capitalization* — Задача на работу со строками (перевод первой буквы слова в верхний регистр).

* **leetcode_tasks/** — Решения задач на массивы и циклы с LeetCode. Каждое решение оформлено в виде связки заголовочного файла (.h) и файла реализации (.cpp) для модульности кода.
  * *Concatenation of Array* — Задача на дублирование элементов массива.
  * *Max Consecutive Ones* — Поиск максимального количества идущих подряд единиц в бинарном массиве.
  * *Shuffle the Array* — Задача на тасование элементов массива по правилу (x1, y1, x2, y2...).

* **oop_basics/** — Примеры кода для освоения базовых концепций объектно-ориентированного программирования.
  * *классы_конструкторы.cpp* — Изучение создания классов, принципов работы конструкторов и деструкторов.
  * *перегрузки.cpp* — Реализация перегрузки функций и операторов в C++.

## Как запустить

Для сборки и запуска программ вам понадобится компилятор, поддерживающий стандарт C++11 или выше (например, GCC/g++).

1. Склонируйте репозиторий:
git clone https://github.com

2. Перейдите в папку с нужным решением:
cd Cpp_codes/codeforces

3. Скомпилируйте файл:
g++ Soldier_and_Bananas.cpp -o bananas

4. Запустите исполняемый файл:
./bananas

## Требования

* Компилятор G++ (GCC) или Clang c поддержкой стандарта C++17
* Текстовый редактор или IDE (VS Code, Visual Studio, CLion)
